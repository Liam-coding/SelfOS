## Lexical state and special boundaries

Top-level let/const is also shared across the current combined classic scripts even when it is not a window property. In particular, chatCollapsed/chatHistory are read by dimensions; importRunning and knowledgeRecoveryGeneration coordinate jobs; knowledgeOperation belongs to import settings; modelSettingsGeneration/modelListGeneration belong to model settings. Move these into the owning module, use the proposed narrow APIs, and wrap all migrated scripts so repeated script delivery cannot redeclare lexical bindings.

Keep the selfosI18n runtime and selfos-language notification as the single locale authority. Account currently wraps window.fetch and retains selfosFetch; capture the native boundary once, preserve authentication-expiry handling and do not stack wrappers. selfosReadOnlyDemo is supplied by demo rendering rather than these script declarations and must continue to gate corrections.

The static audit intentionally excludes repository tests from the reference table. Before each removal, search tests and migrate intentional browser compatibility calls; do not remove tests merely to make a global disappear. Also verify dynamic action/listener creation and source navigation using the design acceptance matrix.
