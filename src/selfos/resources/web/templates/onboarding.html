Your first useful knowledge

SelfOS organizes project context, personal facts, preferences, reusable lessons and history. Every result keeps its sources; imports create recoverable backups.

Opening or resuming this guide never starts an import. You choose the sources and explicitly start a bounded sample.

Choose local sources

Select Claude Code or Codex conversation folders, or add custom folders containing their JSONL exports. One absolute directory per line.

One absolute path per line, inside a selected folder. Exclusions also filter cached context sent to the model; local history is retained.

Model and network

Use Settings to choose an Anthropic or OpenAI-compatible model and your proxy. Keys remain in your existing local model configuration.

Save and test connection makes one request to the configured model. Navigation through this guide makes none.

Review a small local sample

The selected excerpts below and source-supported cached project context will be sent to your configured model only when you click Start sample. This preview stays local.

Default: at most 2 files (8 MiB each), 20 messages per session, 2 compact parts and 12 total model requests including retries and reviews. Directory enumeration is limited to 2,000 entries.

Your results and next step

Saved checkpoints are recoverable progress. Knowledge becomes visible in the library after publication. Stopping keeps checkpoints; resuming the same preview keeps its remaining allowance.

Process more opens a new preview: at most 4 files, 40 messages per session, 4 parts and 24 total requests. It does not start automatically.
